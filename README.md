# Personal Portfolio

A responsive, single-page portfolio with a warm cream, sage, and forest-green visual theme.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html` and confirm the name.
2. Replace the introductory paragraph with your real course, college, and interests.
3. Replace the sample skills with skills you have actually practised.
4. Add real project descriptions and links.
5. Replace `your.email@example.com` with your email address.
6. Replace the `#` social links with your LinkedIn and GitHub profile URLs, or remove them.

## Preview locally
Open `index.html` in a web browser.

## Publish with Render
1. Create a public GitHub repository and upload these four files.
2. In Render, choose **New + → Static Site** and connect the repository.
3. Use branch `main`.
4. Leave Build Command blank.
5. Set Publish Directory to `.`.
6. Create the site.

The site is static and does not require a build command.
